### WEB-SEC-004 — Unvalidated href Allows javascript: Protocol

**Issue:** Links in HeroBlock, BannerBlock, TimerBlock, RelatedContentBlock, and FormBlock used unsanitized URLs.

**Fix Applied:**
1. **Created security utility:** Added `sanitizeUrl()` to `web/lib/security.ts`
   ```typescript
   export function sanitizeUrl(url: string | undefined | null, allowRelative = true): string {
     if (!url) return '';
     const trimmedUrl = url.trim();
     
     // Allow relative URLs
     if (allowRelative && trimmedUrl.startsWith('/')) return trimmedUrl;
     
     // Only allow http and https protocols
     if (!/^https?:\/\//i.test(trimmedUrl)) {
       console.warn(`Blocked unsafe URL protocol: ${trimmedUrl}`);
       return '';
     }
     
     // Validate protocol using URL parser
     try {
       const parsed = new URL(trimmedUrl);
       if (parsed.protocol !== 'http:' && parsed.protocol !== 'https:') {
         console.warn(`Blocked unsafe URL protocol: ${parsed.protocol}`);
         return '';
       }
       return trimmedUrl;
     } catch (error) {
       console.warn(`Invalid URL: ${trimmedUrl}`);
       return '';
     }
   }
   ```

2. **Updated 5 components:**
   - `web/components/blocks/HeroBlock.tsx` — CTA link
   - `web/components/TemplatesComps/Banner/BannerBlock.tsx` — Slide links and CTA buttons
   - `web/components/TemplatesComps/Timer/TimerBlock.tsx` — CTA link
   - `web/components/TemplatesComps/RelatedContent/RelatedContentBlock.tsx` — Item links
   - `web/components/TemplatesComps/Form/FormBlock.tsx` — Terms & Conditions link

**Verification:** All URLs validated before rendering in href attributes.

### WEB-SEC-005 — CSS Injection via Background Image URL

**Issue:** `image_url` interpolated directly into inline `style` attribute in HeroBlock.

**Fix Applied:**
1. **Created security utility:** Added `sanitizeCssUrl()` to `web/lib/security.ts`
   ```typescript
   export function sanitizeCssUrl(url: string | undefined | null): string {
     const sanitized = sanitizeUrl(url, false);
     if (!sanitized) return '';
     // Remove characters that could break out of url()
     return sanitized.replace(/[()'"\\]/g, '');
   }
   ```

2. **Updated component:** `web/components/blocks/HeroBlock.tsx`
   ```typescript
   // BEFORE:
   style={{ backgroundImage: `url(${hero.image_url ?? ''})` }}
   
   // AFTER:
   const safeBgUrl = sanitizeCssUrl(hero.image_url);
   style={{ backgroundImage: safeBgUrl ? `url(${safeBgUrl})` : undefined }}
   ```

**Verification:** Background image URLs sanitized to prevent CSS injection.

### WEB-SEC-006 — Form Submission Endpoint Path Traversal

**Issue:** `formType` from template data used to construct fetch URL without validation.

**Fix Applied:**
1. **Created security utility:** Added `sanitizeFormType()` to `web/lib/security.ts`

   export function sanitizeFormType(formType: string | undefined | null): string | null {
     if (!formType) return null;
     const sanitized = formType.trim().replace(/[^a-zA-Z0-9_-]/g, '');
     if (sanitized !== formType) {
       console.warn(`Invalid form type sanitized: "${formType}" -> "${sanitized}"`);
